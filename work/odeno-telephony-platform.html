Work  /  Odeno

Odeno Telephony Solutions Platform

UX/UI Design, Web Development
Overview

Odeno is Denmark's biggest and most intelligent platform for companies seeking telco solutions — mobile subscriptions, internet, switchboards, wifi and more. My goal was to redesign the tool, improve the user experience, and implement it using code.

Methods & tools
  • Prototyping
  • Adobe XD
  • HTML/CSS
  • JavaScript
01

Design

Reworking the flow

Using Adobe XD, I recreated the flow users go through when finding the best-matching telco solution, taking the outdated design and giving it a fresh look. I built high-fidelity mockups and turned them into an interactive prototype so my peers could walk through the flow and confirm it worked.

02

Development

From design to code

The next step was implementation. Using my coding knowledge, I took part in the frontend development of the tool, translating the approved designs into working HTML, CSS and JavaScript.
